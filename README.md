# Crib N Connect – Mobile App (Expo)

Crib N Connect is a mobile-first experience to find and book stylish apartments, parties, and events. Plan your next groove or host a premium space — all in one place.

## 📱 Built With

- **Framework:** Expo + React Native
- **State Management:** Zustand
- **Networking:** Axios + React Query
- **Database:** MongoDB Atlas (via APIs)
- **Authentication:** Firebase Auth (Google Login)
- **Messaging:** Firestore
- **Design:** NativeWind + Lottie + Lucide Icons
- **Build Tool:** EAS Build

## 🔥 Features

- Smooth onboarding & Firebase auth
- Search & filter apartments and events
- Host upload flow with AI-generated formatting (coming soon)
- Linkup/Meetups and RSVP
- In-app chat (Firestore)
- Booking and KYC (upcoming)
- Notifications and event reminders
